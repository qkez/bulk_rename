# Bulk Rename

CLI-утилита для массового переименования файлов в папке. Поддерживает префиксы, нумерацию, регулярные выражения и смену регистра.

## Что умеет

- Массовое переименование файлов в папке по заданному шаблону
- Добавление префикса с нумерацией (`vacation_001.jpg`, `vacation_002.jpg`, ...)
- Удаление части имени через регулярное выражение
- Смена регистра (верхний / нижний)
- **Dry-run режим** (по умолчанию) — показывает что будет сделано, не трогая файлы
- Проверка на коллизии — не перезапишет существующие файлы

## Стек

- Python 3.10+
- Только стандартные библиотеки: `argparse`, `re`, `pathlib`
